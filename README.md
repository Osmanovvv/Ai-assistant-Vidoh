# ВЫДОХ

Telegram-бот, который принимает поток мыслей голосом или текстом, раскладывает его по темам, ведёт бэклог задач и доводит до одного конкретного следующего действия.

## Стек

| Слой    | Технология                                        |
| ------- | ------------------------------------------------- |
| Язык    | Node.js 24, TypeScript в строгом режиме           |
| Бот     | grammY (Bot API 9.5+ — нужны темы в личных чатах) |
| API     | Express 5                                         |
| База    | PostgreSQL 17 + pgvector                          |
| Очереди | Redis + BullMQ                                    |
| Админка | React + TypeScript                                |
| Тесты   | Vitest, Playwright, GramJS                        |
| Хостинг | Docker Compose, Caddy                             |

## Требования к окружению

- Node.js 24+
- Docker и Docker Compose
- ffmpeg (в образе устанавливается автоматически)

## Запуск для разработки

```bash
npm install
cp .env.example .env      # заполнить BOT_TOKEN и остальное
npm run infra:up          # Postgres и Redis в Docker
npm run db:migrate
npm run dev
```

Вебхук Telegram требует HTTPS, поэтому локально нужен туннель (cloudflared, ngrok) — его адрес указывается в `PUBLIC_URL`.

## Команды

| Команда                           | Что делает                             |
| --------------------------------- | -------------------------------------- |
| `npm run dev`                     | Запуск бота в режиме разработки        |
| `npm run build`                   | Сборка                                 |
| `npm run typecheck`               | Проверка типов                         |
| `npm test`                        | Модульные и интеграционные тесты       |
| `npm run db:generate`             | Генерация миграции по изменённой схеме |
| `npm run db:migrate`              | Применение миграций                    |
| `npm run infra:up` / `infra:down` | Локальные Postgres и Redis             |

## Структура

```
apps/
  bot/        Telegram-бот, конвейер обработки, API админки
  admin/      Админ-панель (React)
docs/         Проектная документация (не в репозитории)
```

## Документация

Техническое задание, разбор требований и план разработки в репозиторий не входят: репозиторий публичный, а документы содержат коммерческие данные заказчика. Они ведутся отдельно.
